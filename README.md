# 手機姿態 3D 教具

- 作者：李振偉老師（範例）
- 網址：https://appjust.github.io/phone-twin/
- 對應作業：(作業)Codex × 手機感測器網頁 App，第 25 題（備用題，老師範例）

轉動手機，畫面上的 3D 手機會跟著轉；打開除錯面板，看加速度計、陀螺儀和方向的數字怎麼變。只用動作感測器，不用鏡頭、麥克風、定位，數值只在手機上計算、不上傳。

## 使用方式

1. **手機**：iPhone 用 Safari、Android 用 Chrome 打開網址（不要在 LINE、Instagram 裡直接開）。按「開始」，iPhone 會跳出權限視窗，選「允許」。
2. **電腦**：按「開始」後會自動進入「模擬模式」。用 α、β、γ 三個滑桿模擬手機的方向，按「搖一下」模擬搖晃。
3. 「認識數值導覽」會依序請你做 5 個動作：平放、立起、向左傾、搖一下、平放轉一圈。每完成一個會響一聲（Android 加短震動），並說明哪個數字變了。
4. 「校正」把目前的姿勢當作模型的正面，再按一次取消；「除錯」打開即時數值表；「音效」可以靜音。

## 架構

| 檔案 | 負責 |
|---|---|
| `index.html` | 開始畫面、主畫面、底部署名與版本號 |
| `sensor.js` | 要權限、監聽 `devicemotion`／`deviceorientation`／`deviceorientationabsolute`、平滑、校正、模擬模式；用同一個介面把數值交給 app.js |
| `config.js` | 所有門檻和參數，每個數字有中文註解 |
| `app.js` | 3D 模型、小圖表、導覽規則、音效、除錯面板；不直接監聽感測器事件 |
| `style.css` | 版面，手機直式為主，轉成橫式時提示「請轉回直式」 |

**介面**：`Sensor.init(onReading, onStatus)` 設定回呼，`Sensor.start()` 在按鈕點擊裡要權限並開始讀取。每一幀 `onReading` 收到同樣格式的資料：

```js
{ mode: "sensor" | "sim", hz, t,
  raw:    { ax, ay, az, gx, gy, gz, ra, rb, rg, alpha, beta, gamma, heading },
  smooth: { alpha, beta, gamma, accMag, rotMag },
  R: 3×3 旋轉矩陣（已扣掉校正） }
```

**模擬模式怎麼接上**：沒有感測器時，`sensor.js` 改用滑桿的值，每秒產生 60 筆假資料（加一點雜訊），並用旋轉矩陣算出重力在手機座標的分量（`Rᵀ·(0, 0, 9.81)`），填進同一個 `raw`。`app.js` 分不出資料是真的還是模擬的。

**什麼時候進模擬模式**：

- 電腦上權限被拒絕（新版 Chrome 在電腦上也有 `requestPermission()`，沒有感測器時會回 `denied`）。
- 按開始後 2 秒內沒有收到感測器資料，或數值都是 `null`。
- 手機上權限被拒絕時，畫面說明怎麼重新允許，並提供「改用模擬模式」按鈕。

**3D 模型**：依規格 `R = Rz(α)·Rx(β)·Ry(γ)` 算出旋轉矩陣，畫面座標的 y 朝下，所以換成 `T = S·R·S`（`S = diag(1, −1, 1)`）再用 CSS `matrix3d` 套到模型上，鏡頭從上方往下看。

## 門檻說明（config.js）

| 參數 | 值 | 意思與決定方式 |
|---|---|---|
| `smoothing` | 0.18 | 每筆新資料只採用 18%。0.3 以上手抖時模型會晃，0.1 以下轉動時跟不上 |
| `noDataMs` | 2000 | 按開始後 2 秒沒資料就進模擬模式；手機通常 0.1 秒內就有資料 |
| `holdMs` | 600 | 導覽動作要維持 0.6 秒，避免轉動途中經過就被判定 |
| `cooldownMs` | 900 | 完成一個動作後 0.9 秒內不判斷下一個，避免一次算兩個 |
| `flatDeg` | 15 | 平放：β、γ 都在 ±15° 以內 |
| `uprightDeg` | 60 | 立起：β 大於 60° |
| `tiltLeftDeg` | −30 | 向左傾：γ 小於 −30°，同時 β 在 ±45° 以內 |
| `shakeMs2` | 12 | 搖一下：平滑後、去掉重力的加速度大於 12 m/s²；走路晃動大約 2–5 m/s² |
| `turnDeg` | 330 | 平放轉一圈：平放時 α 累積轉動超過 330°；中途拿起來就重算 |
